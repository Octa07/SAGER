# Índice de evidencias

- `antes/` y `despues/`: capturas comparativas del prototipo y los cambios de interfaz. Verifica cada caso antes de presentarlo como ejecución funcional.
- `ejecuciones/INFORME_EJECUCION_PRUEBAS.md`: corrida más reciente; distingue pruebas pendientes, parciales y observadas.
- `ejecuciones/`: capturas y consultas que corresponden a esa corrida.
- `ejecuciones/historico_2026-10-31/`: resultados y capturas de una ejecución anterior; no mezclar con la corrida más reciente.
